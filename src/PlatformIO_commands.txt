PlatformIO commands. Run from terminal

<target> - choose one of the [env:] 'environments' from platformio.ini:
esp32-poe-iso
esp32-s3-devkitc-1

Build filesystem: 
pio run -e <target> -t buildfs

Flash filesystem: 
pio run -e <target> -t uploadfs

Build project: 
pio run -e <target>

Build & flash project: 
pio run -e <target> -t upload

Memory footprint: 
pio run -e <target> -t size
